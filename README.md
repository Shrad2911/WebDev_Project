# 🎮 Simon Says Game

A browser-based **Simon Says Game** built using **HTML, CSS, and JavaScript**. The game challenges players to remember and repeat an increasingly long sequence of colors, helping demonstrate core JavaScript concepts such as DOM manipulation, event handling, arrays, timers, and local storage.

---
## 🚀 Features

- 🎮 Interactive Simon Says gameplay
- 🧠 Random color sequence generation
- ✨ Button flash animations
- 🌙 Dark / Light mode
- 💾 Theme preference saved using Local Storage
- 🏆 Highest Score Tracker
- 🔄 Start Game & Play Again functionality
- 📱 Responsive and clean user interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

## 📚 Concepts Practiced

- DOM Manipulation
- Event Handling
- Arrays
- Functions
- Conditional Statements
- Timers (`setTimeout`)
- Local Storage
- CSS Animations & Transitions
- Game State Management

---

## 🎯 How to Play

1. Click the **Start Game** button.
2. Watch the color flashed by the game.
3. Repeat the sequence by clicking the buttons in the correct order.
4. Each level adds one new color to the sequence.
5. The game ends when an incorrect button is pressed.
6. Try to beat your highest score!
